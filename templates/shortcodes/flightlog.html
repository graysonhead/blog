{#- Flight telemetry figure: stats, ground track map, and altitude/groundspeed profile. Usage in a post (with `[extra] applet = true`): {{ flightlog(flight=35244538, tz="America/Chicago") }} {{ flightlog(src="2026-10-14-kxyz.kmz", title="KXYZ to KABC") }} `flight` is a MyFlightbook flight ID (`scripts/mfb_sync.py flights` lists them). `mfb_sync.py flight ID` (or `sync`, which fetches any referenced flight that's missing) snapshots its track and logbook fields into static/data/flights/mfb-ID.{gpx,json}; the logged details render here at build time, and the track is drawn in the browser. `src` is a .gpx, .kml or .kmz of your own in static/data/flights/ (MyFlightbook's GPX and KML exports both work as-is). The track file is published (the browser has to fetch it) but not linked from the figure. The departure METAR (the last report before takeoff, from the Iowa Environmental Mesonet archive) is added to the snapshot by the sync and shown under the logbook row when one was found. Annotations: use the block form and list them in the body, one per line. Times are local to `tz` (or end them with Z for UTC); a range marks a maneuver, a single time a moment. The middle field is the key, which a post links to with {{ mark(key="engine", text="...") }}; leave it out to derive one from the label. {% flightlog(flight=35333596, tz="America/Chicago") %} 09:40 | engine | Engine failure 09:44-09:51 | turns | Turns around a point | max-alt avg-alt gs-dev {% end %} The optional last field turns on per-range stats, any of: start-alt, max-alt, avg-alt (time-weighted), gs-dev (largest groundspeed swing from the range's average), alt-dev (largest altitude swing from the range's time-weighted average).
